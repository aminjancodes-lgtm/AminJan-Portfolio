# Amin Jan — Software Engineer Portfolio

A multi-page portfolio website built with plain HTML, CSS, and JavaScript.

## Structure

- `index.html` — home page
- `about.html` — profile and toolkit
- `projects.html` — project index
- `experience.html` — professional experience
- `contact.html` — contact page
- `projects/` — individual project pages
- `css/style.css` — shared visual system and responsive styles
- `js/main.js` — shared navigation and reveal animations
- `assets/` — future images, icons, and project screenshots

## Run locally

Open `index.html` in a browser or serve the folder with a simple static server.

## Notes

The site intentionally avoids frameworks so the structure stays easy to understand, edit, and deploy.
